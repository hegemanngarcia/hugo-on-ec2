How to deploy an n8n server on an AWS EC2 server

January 9, 2026

Introduction

Wenn du einen n8n server auf AWS EC2 aufsetzen möchtestm, dann bist du hier genau richtig.

Voraussetzungen

  • Du hast bereits einen AWS account

EC2 Server Grösse

Je nachdem was du mit deinem n8n server vor hast, bestimmt welche Servergrösse für dich geeignet ist. Ich habe die Grösse TODO gewählt um am Anfang erstmal geringe Kosten zu haben. Die Grösse reichte mir um einen n8n server und nebenher eine Hugo website zu hosten. Du kannst damit schon erste workflows erstellen die AIs wie Gemini oder ChatGPT benutzen. Einen Telegram Chatbot konnte ich damit auch problemlos erstellen.

Domain

Die Domain ist nicht unbedingt notwendig für das aufsetzen der Instanz. Allerdings bin ich ohne Domain ziemlich schnell an die Grenzen gestossen. Wenn man zum Beispiel ein Telegram Bot schreibt, dann braucht dieser eine Domain um den n8n Server erreichen zu können. Du kannst direkt in AWS mit dem Service Route 53 eine Domain kaufen. Das geht recht zügig und ist nicht wahnsinnig teuer. Ich fasse aber unten nochmal die Kosten zusammen.
